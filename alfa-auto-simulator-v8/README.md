# WEB-тренажёр «1С:Альфа-Авто 6.1» — версия v8

Автономная учебная имитация документов грузового автосервиса. Работает локально в браузере без подключения к рабочей или тестовой базе 1С, MAX, электронной почте и PostgreSQL. Фамилии, телефоны, организации, автомобили и позиции справочников — вымышленные.

## Запуск

1. Скачайте `AlfaAuto_Trainer_v8.html`.
2. Откройте файл в Яндекс Браузере, Chrome или Edge. Интернет не требуется.
3. Для выбора отдельного документа или задания используйте **«Сценарии»**. В режиме «Обучение» подсказки показываются при наведении, в «Экзамене» скрыты.
4. Режим **«Вид только формы 1С»** скрывает учебную оболочку для оценки визуального сходства.

Учебные записи хранятся в локальном хранилище браузера. Если доступен прогресс v7 в том же браузере и с тем же источником, v8 при первом запуске может прочитать его. Для сброса есть команда «Сбросить учебные данные». Для разных браузеров общая учебная база не создаётся.

## Основные возможности

- **17 экранов / 18 учебных сценариев**, включая «Событие», задачи CRM, КП, автоматическую КП, ОЗЧ, запись на ремонт, заказ-наряд, MAX, финблокировку и новый «Календарь планирования».
- **Запись на ремонт**: самостоятельное заполнение клиента, автомобиля, даты и времени; проверка обязательных реквизитов, сохранение и повторное открытие по номеру.
- **MAX**: при первом учебном проведении записи с телефоном формируется журнал SMS-приглашения, а при наличии активного учебного чата и согласия — сообщение MAX. Симуляция согласия, отказа и отзыва. При отсутствии активного согласия сообщения сотрудников блокируются. Настоящая рассылка не выполняется.
- **Календарь планирования**: записи за выбранный день, цветовые статусы, переход в запись и связанную задачу. Вручную запускается учебный регламент: уведомление в 10:00, повторы в 12:00 и 14:00, задача «Обзвон клиента» в 15:30 при отсутствии ответа. Статусы и история не подменяют реальные регистры 1С.
- **Заказ-наряды**: самостоятельные документы с номерами `ЗН-00001`, `ЗН-00002` и т.д.; отдельные табличные части авторабот, товаров, материалов заказчика; перечень сохранённых ЗН, повторное открытие конкретного ЗН, завершение ремонта и связь с заявкой на ремонт.
- **КП**: отдельные калькуляции, наборы работ и товаров, согласование позиций, перенос в ЗН, проценка ОЗЧ и учебная печатная форма с суммами.
- **Задачи CRM**: принятие групповых задач, работа по предмету, смена статуса КП, результат выполнения и связь с документом.

## Важные ограничения

- Внешний вид **не подтверждён как пиксельно идентичный** текущей тестовой базе `aa6_ea_test9`. «Календарь планирования» реконструирован по тексту инструкции MAX, а не по полному эталонному скриншоту. Для точной приёмки необходима визуальная сверка с доступным тестовым веб-клиентом.
- Учебный регламент MAX выполняется только по нажатию в тренажёре. Таймеры не работают в фоне; SMS, MAX-сообщения и email не отправляются.
- Реальных цен, нормочасов, остатков склада, проводок 1С и серверных документов нет. Справочники и печатные формы демонстрационные.
- Маршрут стандартного ремонта, группы пользователей и фактические права должны быть подтверждены администратором действующей 1С до использования для аттестации сотрудников.

## Источники

- `Инструкция_мастера-приемщика_1С_Альфа-Авто_6.1(2).docx` — рабочий стол, события, задачи, КП, стандартный и экспресс-маршрут.
- `Работа с мессенджером «MAX» .docx` — приглашение из заявки, согласие на ПД, регламент 10:00 / 12:00 / 14:00 / 15:30, реакции клиента, календарь.
- `Работа КП(1).docx` и `Автоматическая КП по дефектовке.docx` — калькуляции и проценка ОЗЧ.
- `Инструкция по работе с экспресс заказ.docx` — ограничения экспресс-ЗН.

Внутренние Word/PDF-инструкции и их оригинальные скриншоты намеренно **не включены** в публичную сборку.

## Разработка и проверка

`index.html` подключает `src/styles.css`, `src/skin.css` и `src/app.js`. Для воспроизводимой сборки автономного HTML выполните:

```bash
python build.py
node --check src/app.js
```

Интерактивные проверки выполняются в Chromium (Playwright):

```bash
python qa/test_v4_regression.py         # 9
python qa/test_v5_browser.py            # 12
python qa/test_v6_workflows.py          # 6
python qa/test_v7_desktop_events.py     # 8
python qa/test_v8_calendar_max.py       # 9
python qa/test_v8_repair_documents.py   # 5
```

Итого **49/49** проверок в изолированном браузере на момент выпуска. Подробности: `QA_REPORT.md` и `qa/test_v8_*.json`.

## Безопасность

Основной сайт `ea-itus.ru`, действующая 1С, тестовая база, Bitrix24, MAX, PostgreSQL и основная ветка GitHub не изменяются. Сборка не выполняет сетевых запросов к этим системам.
