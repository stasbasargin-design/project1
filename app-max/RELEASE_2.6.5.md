# Версия 2.6.5

## Создание УРВ

1. «Создать пакет УРВ» запрашивает /worktime/orders/works с orderRef и withoutActivePackages:true. Сервер 1С должен вернуть только работы, не включённые в активные пакеты. Клиент дополнительно исключает available:false, hasActivePackage:true, непустой activePackageRef или activePackages.
2. После выбора работ и «Подтвердить работы» запрашивается /worktime/executors/list по цеху. Верхняя кнопка «Делаю сам» выбирает текущего сотрудника; ниже — коллеги и отдельная отметка «Я участвую» для совместной работы. Неотмеченный текущий сотрудник не добавляется автоматически.
3. Один участник — доля 100%, сразу подтверждение. Несколько — отдельное окно процентов, сумма ровно 100%, затем подтверждение состава.
4. Только «Подтвердить и создать пакет» отправляет проверку участия и создание в 1С. Создание должно повторно проверить отсутствие активного пакета в транзакции; иначе вернуть 409. Понятие активного состояния определяется учётом в 1С, а не сравнением русских названий статусов в браузере.

## Уведомления и счётчик

Внутренние карточки уведомлений убраны. Удалены дублирующие уведомления и автоматический запрос разрешения при любом клике из hotfix-v263.js; совместимость bot ID и закреплённая шапка сохранены. Системные уведомления основного приложения показываются только в фоне и согласно настройкам. Настройки уведомлений открываются только по действию пользователя.

После успешного /clients/messages/read или /internal-chat/messages/read обновляется общий счётчик. Рекомендуемый ответ 1С:

```json
{"success":true,"data":{"read":true,"unreadCount":0,"unreadMessagesCount":0}}
```

unreadCount — остаток в прочитанной переписке; unreadMessagesCount — общий остаток всех доступных пользователю непрочитанных сообщений. Если общего числа нет, клиент вычитает подтверждённое количество текущей переписки из известного общего числа. Другие непрочитанные чаты не обнуляются. Ошибка отметки не снимает индикатор. /notifications/poll должен возвращать актуальный общий unreadMessagesCount (включая 0), а не историческое значение до отметки; агрегат ответа имеет приоритет над вложенными событиями. Клиент игнорирует счётчик опроса, начавшегося до завершённого прочтения.

Основные изменения: assets/app.js, assets/messenger.js, assets/hotfix-v263.js, assets/worktime.js, assets/preview-fixtures.js, контракт 1С и тесты. dist пересобран. Предыдущие инструкции относятся к своим версиям; текущий порядок работы описан здесь.
