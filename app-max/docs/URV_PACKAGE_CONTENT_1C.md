# Состав пакета УРВ в I-MAX

В тестовой публикации 1С расширьте ответ существующего `POST /worktime/packages/list`. Тело запроса остаётся прежним. Для выбранного ЗН приложение передаёт `orderRef`, `onlyOpen: true` и существующий служебный контекст пользователя.

## Где получить данные

1. Примените действующие права пользователя, отбор по ЗН и фильтр открытых пакетов.
2. Для каждого пакета получите **включённые в этот пакет строки работ**. Верните в `works` стабильную ссылку строки ЗН `workRef`, название `name` и числовые нормо-часы `normHours`. Нужна полная норма строки с учётом количества, если оно участвует в расчёте. Сохраните порядок строк пакета.
3. На том же уровне, рядом с `works`, верните `participants` из сохранённого распределения участия самого пакета. Для каждого участника нужны `employeeRef`, отображаемое имя `name` и числовой `percent` в диапазоне от 0 до 100. Используйте фактически назначенные доли. Для распределённого пакета сумма долей составляет 100%.
4. Сохраните `packageRef`, `packageNumber`, `status` и существующую оболочку ответа. Возвращайте сведения обо всех найденных пакетах одним ответом. Метод используется только для чтения.

## Пример ответа

```json
{
  "success": true,
  "data": {
    "packages": [{
      "packageRef": "PACKAGE_GUID",
      "packageNumber": "УРВ-0007",
      "status": "В работе",
      "works": [
        {"workRef": "ORDER_ROW_1_GUID", "name": "Замена колодок", "normHours": 2},
        {"workRef": "ORDER_ROW_2_GUID", "name": "Проверка тормозной системы", "normHours": 0.5}
      ],
      "participants": [
        {"employeeRef": "EMPLOYEE_A_GUID", "name": "Антон Орлов", "percent": 60},
        {"employeeRef": "EMPLOYEE_B_GUID", "name": "Илья Соколов", "percent": 40}
      ]
    }]
  }
}
```

Замените условные ссылки в примере идентификаторами из тестовой базы. Передавайте числа без единиц измерения и знака процента. Клиент суммирует `normHours` и показывает расчётные часы сотрудника по формуле `сумма норм пакета × percent / 100`. Результат для просмотра округляется до двух знаков. В примере норма пакета — 2,5 н·ч, доли сотрудников — 1,5 и 1,0 н·ч. Это расчёт для показа состава, фактическую выработку предоставляет её действующий метод.

## Пустые и исторические записи

Возвращайте `works: []` для пакета без работ и `participants: []` для пакета без назначений. Если сведения неизвестны, оставляйте поле отсутствующим или передавайте `null`. Для неизвестной нормы строки передавайте `normHours: null`. Значение `0` означает известную нулевую норму. При неполных нормах клиент показывает известные сведения и оставляет общий итог и расчётные часы неопределёнными.

## Как принять на тесте

На одном доступном ЗН откройте «Пакет УРВ» и раскройте «Состав пакета». Сверьте ссылки, работу с дробной нормой, общую норму и проценты с документом 1С. При наличии двух пакетов убедитесь, что каждый показывает свои строки и своих исполнителей. Раскрытие состава сохраняет выбор текущего пакета. Сценарий проверки не требует создания, запуска или закрытия пакета.
