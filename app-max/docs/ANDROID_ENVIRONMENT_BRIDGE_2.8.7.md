# Android: переключение 1С в 2.8.7

База выпуска: 2.8.6, `5832ec189c2beb086790f52bda31a8781d668d32`.

В 2.8.6 код искал компонент Environment только через `Capacitor.registerPlugin`. Статическая Android-сборка предоставляет зарегистрированный Java-компонент через `Capacitor.Plugins.Environment`, поэтому приложение ошибочно требовало обновить уже актуальный APK.

Исправление сначала использует внедрённый нативный компонент, сохраняя альтернативную регистрацию для SDK-сборок. Перед вызовом проверяется наличие `setPushContext`. При отсутствии компонента или ошибке сохранения контекста переключение по-прежнему блокируется: защита от уведомлений чужой базы не отключается.

Регрессионный тест воспроизводит ошибку 2.8.6 с `Plugins.Environment` и без `registerPlugin`. На исправленном коде проверяются обе схемы подключения, цикл тест → бой → тест, отключение уведомлений перед переключением, недоступный компонент и ошибка нативного сохранения.

Версии runtime/npm/lock/APK: 2.8.7, Android versionCode 2807. Package, подпись, нативный Java-компонент, методы 1С, серверные настройки и схема очередей не меняются. Новых доработок 1С для этого исправления нет. Для автоматических Push боевой базы сохраняется инструкция `ENVIRONMENTS_1C_2.8.6.md`.

Физический Android требует проверки после установки: профиль → тестовая 1С → боевая 1С; сообщение об обновлении не должно появляться. В каждый момент отображаются данные выбранной базы, а уведомления старого контура подавляются. Не удалять приложение и не очищать его данные для установки обновления.
