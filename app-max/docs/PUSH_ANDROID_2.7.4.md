# I-MAX 2.7.4 — восстановление Android Push

## Что исправлено

В APK 2.7.3 нативный модуль Firebase Push присутствовал, но его JavaScript
прокси не регистрировался в `Capacitor`. Поэтому приложение ошибочно считало
Android-устройство браузером и показывало «Разрешение устройства: не
поддерживается». FCM-токен не обновлялся, а Firebase отклонял устаревшую
регистрацию устройства.

Версия 2.7.4 регистрирует `PushNotifications` через
`Capacitor.registerPlugin('PushNotifications')` до запроса разрешения. Это не
меняет контракты 1С, серверные маршруты, авторизацию или существующие токены
в браузере.

## Установка

1. Установить APK версии **2.7.4** поверх прежнего I-MAX.
2. Открыть приложение и войти по своему ID.
3. В «Уведомлениях» нажать «Разрешить уведомления на устройстве», если Android
   ещё не выдал разрешение.
4. Убедиться, что в настройках больше не показано «не поддерживается».
5. Перезапустить приложение один раз: FCM зарегистрирует актуальный токен,
   который будет отправлен в 1С через `/notifications/push/subscribe`.

## Проверка

- Отправить из 1С тестовое событие на зарегистрированное устройство.
- В журнале Timeweb ожидается `[push] event sent=1 failed=0`.
- При `failed=1` повторно открыть приложение после входа: токен будет
  зарегистрирован заново. Токены в журнал не выводятся.

## Версия

- Android `applicationId`: `ru.eazia.imax`.
- Версия: `2.7.4`.
- `versionCode`: `2704` — Android обязательно распознает APK как обновление
  версии 2.7.3.
