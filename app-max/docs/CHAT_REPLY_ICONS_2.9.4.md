# Иконки ответа и реакции I MAX 2.9.4

База: production 2.9.3, main `5269f8c5d6a993729c0eff230d1a582e809206e0`.

Во внутреннем чате под подтверждённым сообщением текстовая кнопка ответа заменена изогнутой SVG-стрелкой вправо. Соседняя кнопка реакции использует SVG-смайлик в том же стиле. Красные контуры, светлый фон и скругление соответствуют I-MAX. Зона нажатия — 44 на 44 пикселя. Есть подсказки, aria-label, фокус клавиатуры и обратная связь при нажатии; уменьшение движения учитывает системную настройку.

Нажатие стрелки выбирает исходное сообщение и показывает цитату над полем ввода. Оно не отправляет запрос записи. Текст или вложение отправляются существующей кнопкой с прежним replyToMessageRef. Смайлик под сообщением открывает выбор реакции; смайлик возле поля ввода по-прежнему вставляет эмодзи в текст.

Не менялись API, авторы сообщений, очереди, ID повторов, работа с файлами, Push, контуры и правила включения функций. В клиентском чате новые внутренние действия не появляются.

## Поддержка со стороны 1С

Наличие готовых методов само по себе не включает кнопки. Существующий /auth/max должен объявить поддержку в data.chatCapabilities.internal. Для ответа data в виде массива блоков добавить отдельный блок, не заменяя user, availableTabs и идентификаторы ботов:

```json
{
  "chatCapabilities": {
    "internal": {"replies": true, "reactions": true}
  }
}
```

Если data — объект, добавить chatCapabilities как его поле. Включать только реализованные методы. После изменения требуется повторный вход в приложение. Настройки не подменяются фиктивными флагами на клиенте. В проверке 18 ноября 2026 года обе базы отвечали без chatCapabilities; это отдельно от изменения иконки.

## Проверки

Реальный браузер: телефон и широкий экран, размер зон нажатия, SVG и доступные подписи, отсутствие горизонтального переполнения, выбор цитаты без запроса отправки, однократная обычная отправка с правильным replyToMessageRef и существующие проверки реакций. Авторизация в браузерном тесте использует массив блоков, как опубликованная 1С. Регрессия без объявленной поддержки сохраняет скрытые кнопки. Полный набор тестов и сборка обязательны.

Изображения тестового интерфейса используют только искусственные данные. Реальные ответы и реакции нельзя объявлять проверенными, пока опубликованная 1С не объявит поддержку и не пройдёт согласованный сценарий. Production-выпуск этой версии требует отдельного подтверждения владельца по правилам репозитория.
