# ИТУС — проверочная веб-версия 25 сентября 2026

Самая быстрая проверка: распакуйте архив и откройте OPEN_REVIEW.html двойным щелчком.
Это автономная демонстрация изменённого интерфейса с тестовыми данными.
Системные уведомления/Service Worker в режиме file:// недоступны.

Для проверки через локальный веб-сервер нужен Node.js 20 или новее.
На Windows запустите START_REVIEW_WINDOWS.bat. На Linux/macOS:

```sh
PORT=8081 node server.mjs
```

Откройте http://localhost:8081/preview.html для проверки интерфейса без запросов в 1С.
Верхняя жёлтая полоса обозначает тестовые данные. Роли переключаются ссылками.
Отправка сообщений и фотографий здесь только имитируется в памяти браузера.
Для проверки реальной интеграции откройте http://localhost:8081/ — это обычное
приложение с текущим прокси к тестовой 1С. Действия здесь записывают данные в 1С.
Самостоятельно файлы на действующем сервере не заменяются.

## Изменения

- Счётчик непрочитанных сообщений бота в шапке для master. Неизвестное значение — «—», не ноль.
- Ролевой запрос /notifications/poll и дополнительная фильтрация ответа:
  master → new_messages; executor → executor_assigned; tech → quality_control_requested.
- Имя из user.name, data.user.name или data.name; поддержка массива полей пользователя.
- Автор исходящего сообщения — текущий пользователь; входящего — отправитель из 1С.
- Даты преобразуются в русский формат и локальный часовой пояс устройства.
  Можно задать DISPLAY_TIME_ZONE: 'Asia/Yekaterinburg' в config/itus.config.js.
- Раздельные кнопки «Камера» и «Галерея» после выбора «Фото».
- Непрозрачные меню, читаемые шрифты, более контрастные подписи.
- Профиль → Уведомления: переключатели событий своей роли, системные уведомления.
  Настройки отдельные для пользователя и устройства. Счётчик не зависит от переключателя.
- Системные уведомления через Service Worker по разрешению пользователя,
  только пока браузер продолжает исполнять страницу. Закрытое приложение не поддерживается.

## Что требуется проверить/настроить на сервере

1. Камера: ранее домен возвращал Permissions-Policy: camera=().
   В deploy/ea-itus-location.conf подготовлено разрешение camera=(self), microphone=(self)
   только для маршрута приложения. Перенесите изменения также в постоянный источник
   конфигурации портала, иначе генератор Nginx их затрёт. Проверка nginx -t обязательна.
   Это не обновляет Android-оболочку: старый APK не обеспечивает полноценный захват камеры.
2. Фото 404: /clients/files/send и /internal-chat/files/send уже указаны в исходном контракте.
   Их существование в опубликованной 1С НЕ подтверждено. Вызовы сохранены без рискованного
   повтора на другой метод; при 404 интерфейс показывает точный отсутствующий метод.
   Нужны реализация/публикация метода в 1С либо согласованный действующий маршрут.
3. /notifications/poll: добавлены поля type (для одной роли), types, role,
   includeUnreadCount и botId. Существующие auth-поля сохранены. Ожидаемый ответ:

```json
{"success":true,"data":{"unreadMessagesCount":3,"nextCursor":"42","events":[{"eventId":"42","type":"new_messages","title":"Новое сообщение","message":"Сообщение клиента","payload":{"unreadCount":3}}]}}
```

1С должна фильтровать данные по авторизованному пользователю, а не доверять роли из запроса.
Общий счётчик возвращать на каждом опросе, включая 0. Идентификаторы событий стабильные.
Укажите действительный MAX_CLIENT_BOT_ID вместо PASTE_..., если сервер требует botId.
В этой версии нет нового метода пометки сообщений прочитанными: это ответственность
действующего /clients/messages/list или согласованного контракта 1С.

## Неподключённые требования

Настоящая доставка при закрытой странице/приложении требует Web Push (подписки,
VAPID-ключи, серверный отправитель с проверкой пользователя и событиями 1С) либо MAX.
Этого в исходном проекте нет. В пакет не встроены вымышленные push-методы или секреты.
Для следующего этапа нужно выбрать канал и согласовать регистрацию устройства.
Ни фоновые push, ни реальная камера телефона, ни отправка в 1С не подтверждены
локальными автоматическими тестами. Старый APK в данном пакете не пересобирался.
