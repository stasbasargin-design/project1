# ИТУС: сайт 2.3.0 и Android 1.1.0

## Проверка до установки
Откройте OPEN_REVIEW.html в браузере компьютера. Это отдельный проверочный
режим с тестовыми данными, без чтения и записи в 1С. Реальная версия — dist/index.html.

## Обновление установленного сайта
Загрузите itus-site-v2.3.0.zip в /root на VPS Timeweb. Выполните только команды:

```bash
RELEASE_DIR=$(mktemp -d /tmp/itus-release.XXXXXX)
unzip -q /root/itus-site-v2.3.0.zip -d "$RELEASE_DIR"
cd "$RELEASE_DIR"
bash UPDATE_ON_SERVER.sh
bash UPDATE_NGINX.sh
curl -i --max-time 20 https://ea-itus.ru/p/max-service/health
```

Обновление рассчитано на уже установленный /opt/itus-max, сервис itus-max,
порт 8080 и подключённый snippet /etc/nginx/snippets/itus-max.conf.
UPDATE_ON_SERVER.sh сохраняет резервную копию в /opt/itus-max-backup-XXXXXX,
не меняет /etc/itus-max.env и сервис systemd. При неудаче проверки локального
сервиса возвращает предыдущие файлы. UPDATE_NGINX.sh обновляет только snippet
приложения, проверяет Nginx перед перезагрузкой; основной конфиг не переписывает.
Если команда завершилась ошибкой — пришлите вывод, не продолжайте установку вслепую.
Ожидаемый health — JSON с success:true и service:ITUS, а не HTML страницы.
Откройте https://ea-itus.ru/p/max-service/ и обновите страницу Ctrl+F5.
INSTALL_ON_SERVER.sh предназначен для первой установки, не для этого обновления.

## Что изменено
- Единый раздел «Чаты»: клиенты/сотрудники согласно правам 1С, переписки/контакты,
  поиск, даты, непрочитанные, черновики отдельно для каждой переписки.
- На компьютере список слева и переписка справа. На телефоне отдельный экран
  переписки с кнопкой назад. Цвета ИТУС, светлый фон и читаемый текст.
- Список чатов не загружает историю каждого чата. История кешируется в текущей
  сессии; кнопка обновления получает новые сообщения. Видео создаётся по нажатию,
  без автозагрузки; base64 преобразуется в файл только при открытии.
- На экране сначала последние 50 сообщений; более ранние можно раскрыть.
  Это ограничение отрисовки, а не серверная пагинация.
- Сохранены исходные маршруты 1С и x-itus-request-id, остальные рабочие разделы.
- Ролевые настройки уведомлений, счётчик, имя сотрудника, дата/время и выбор
  камеры/галереи из предыдущей проверочной версии включены.

## Android
Установите itus-max-android-v1.1.0.apk поверх APK 1.0.0 из предыдущего комплекта.
Пакет ru.eaitus.max, код версии 2, та же подпись; Android 7 и новее.
Если старая установка из другого источника, совместимость её подписи неизвестна.
APK открывает тот же сайт: сначала обновите сайт. Веб и APK работают с одной 1С,
вход выполняется отдельно на каждом устройстве. Интернет обязателен.
Добавлены обработка камеры/галереи, системная кнопка назад внутри чата,
учёт клавиатуры и системных отступов. Камера запрашивается при использовании.

## Что требует проверки на настоящих данных
- Контакты отображаются из доступных тем и групп, а не из полного справочника 1С.
  Создание новых контактов/групп не добавлено без согласованного серверного метода.
- Для полного ускорения видео 1С должна учитывать includeAttachmentContent:false:
  возвращать в истории метаданные, previewUrl и downloadUrl вместо contentBase64.
  Если 1С игнорирует параметр, объём ответа остаётся прежним. Авторизация файлов
  должна сохранять права пользователя. Названия/типы берутся из прежнего контракта.
- Ошибка 404 при отправке вложений требует публикации существующих методов
  /clients/files/send и /internal-chat/files/send на стороне 1С.
- Фоновые push при полностью закрытом приложении не реализованы: нужен серверный
  канал доставки. Ролевые уведомления проверены в открытом приложении.
- APK собран и подпись проверена, но реального Android-устройства для проверки
  камеры, клавиатуры и установки в этой среде нет.

## Откат приложения
Подставьте путь резервной копии, который напечатал UPDATE_ON_SERVER.sh:
`cp -a /opt/itus-max-backup-XXXXXX/app/. /opt/itus-max/`
Затем `systemctl restart itus-max`. Файл настроек подключения не менялся.
