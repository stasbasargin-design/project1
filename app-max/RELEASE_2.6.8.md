# ИТУС 2.6.8 — надёжная отправка и отображение чатов

- Повтор одного и того же неуспешно отправленного сообщения использует прежний `clientMessageId`. Новый идентификатор создаётся только для нового текста или файла.
- История сообщений нормализуется по времени: старые сообщения сверху, последнее сообщение снизу.
- Фотографии с `previewUrl`, `downloadUrl` или Base64 отображаются сразу. Фото, доступные только по `fileRef`, подгружаются автоматически без кнопки раскрытия.
- В мастере пакетов УРВ кнопки возврата используют тот же размер и заливку, что и кнопки подтверждения.

## Фоновые уведомления Android

Текущая APK-оболочка показывает системное уведомление через `ITUSNativeNotifications`, пока WebView выполняет опрос. После полной приостановки приложения Android выполнение JavaScript прекращается. Для гарантированной доставки в фоне требуется серверный push через FCM (Android-проект, ключ подписи, `google-services.json` и отправка события сервером) либо отправка уведомления пользователю ботом MAX. Эти данные в текущем комплекте отсутствуют.
