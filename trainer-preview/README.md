# Альфа-Авто — временная веб-проверка

**Важно:** этот `trainer-preview/index.html` — независимый упрощённый прототип по инструкциям, **не** восстановленный исходный тренажёр v13.1 и **не** попиксельная копия рабочего интерфейса 1С.

## Что доступно
- 8 пошаговых учебных модулей;
- 4 учебных экзамена;
- локальная оценка 0–100, штрафы за ошибки и подсказки;
- журнал результатов в браузере и CSV;
- автономная работа без доступа к боевой базе 1С.

## Что не подтверждено/не включено
- оригинальные изображения и интерактивные области v13.1;
- три видеозаписи MP4 и соответствующие VTT;
- рабочая интеграция с 1С;
- точное визуальное соответствие формам 1С;
- сквозные браузерные автотесты (браузер заблокирован инфраструктурой тестирования).

**Оригинальная сборка:** `Alfa_Auto_Trainer_v13_1_Original_Based.zip` была найдена в библиотеке проекта, но выдача исходных байтов для восстановления недоступна. Переходить от этого прототипа к полной версии следует только после восстановления оригинального исходника.

Боевая система, пользовательские данные, GitHub `main` и VPS не менялись.
