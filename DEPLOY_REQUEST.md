# I-MAX 2.9.9

Выпуск для обновления I-MAX 2.9.8 (`a8a91b7c197d0ac2423b6c797b2731dff1473916`). Ветка `fix/release-2.9.9-chat-defect`. Версия приложения и npm — 2.9.9, Android versionCode — 2909.

В обоих чатах поле ввода занимает место прежней кнопки смайликов. Эмодзи вводятся с клавиатуры. В тёмной теме поле новой записи в дефектовочной ведомости сохраняет читаемый контраст при вводе. В автономном предпросмотре можно открыть учебную ведомость и добавить текст.

Принятые изменения — `744f1d1` и `99bbe6c`. Выпуск проходит через PR и штатные Actions. Перед предложением обновления проверить пакет ru.eazia.imax, совместимость подписи с опубликованной 2.9.8, версию, SHA сборки и доступность APK на Timeweb. После проверки опубликовать манифест с notify=true для существующего отправителя уведомлений старым Android-версиям в боевом контуре. Доработки 1С не требуются.

Для сборок Android в GitHub Actions доступно зеркало Maven Central от Google. Координаты зависимостей и версии библиотек сохранены.
