# ИТУС — управление сервисом

Мобильное веб-приложение для работы с 1С:Альфа-Авто 6.1 через HTTP-сервис `max-service`
и мессенджер MAX. Версия 2.0.1.

## Запуск
- `npm run dev` — локальная разработка (прокси /api/1c на 1С).
- `npm run build` — сборка в `dist`.
- `npm start` — продакшен-сервер (статика + прокси 1С), порт из `PORT`.

## Окружение сервера
- `PORT` — порт (по умолчанию 8080).
- `ONE_C_TARGET` — адрес HTTP-сервиса 1С.
- `ONE_C_TOKEN` — токен интеграции (в браузер не передаётся).
- `PROXY_TIMEOUT_MS`, `MAX_REQUEST_BYTES` — лимиты прокси.

## Проверки
- `npm test` — тесты нормализаторов.
- `ITUS_USER_ID=… npm run check:api` — смоук-проверка HTTP-сервиса 1С.

## Безопасность
Токены ботов MAX и токен интеграции хранятся только в 1С/на сервере.
Все запросы — POST JSON; идемпотентность по requestId/clientEntryId/clientMessageId.
