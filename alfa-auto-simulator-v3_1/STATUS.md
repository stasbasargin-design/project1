# Состояние v3.1
Реализованы три точечные визуальные доработки по имеющимся скриншотам: «Событие», «Контрагент», окно подбора автомобиля. Новый режим «Вид только формы 1С» позволяет убирать учебную оболочку при сравнении.

Проверено: node --check, 10/10 браузерных тестов v3 и отдельная браузерная сверка трёх доработанных форм. Не проверено: совпадение с живой конфигурацией aa6_ea_test9 и все серверные операции 1С.
