# 1С:Альфа-Авто 6.1 — самостоятельный учебный WEB-тренажёр v3.1

**Версия для визуальной сверки по скриншотам из внутренних инструкций. Не является точной копией актуальной тестовой 1С.**

## Запуск
- Простой способ: открыть `AlfaAuto_Trainer_v3_1.html` в Chrome, Edge или Яндекс Браузере.
- Исходники: открыть `index.html` при сохранении каталога `src` с тремя файлами: `app.js`, `styles.css`, `skin.css`.
- Интернет и доступ к 1С не требуются. Данные сохраняются локально в браузере, настоящие документы не создаются.

## Изменения v3.1 относительно v3
- Добавлен переключатель **«Вид только формы 1С»**: скрывает шапку, навигацию, учебную ленту и статус для максимально точного сравнения форм с эталонами. Обратное нажатие возвращает учебную оболочку.
- При отсутствии выбранного сценария учебная лента скрыта, чтобы не отнимать пространство.
- Событие: вкладки и верхние команды переставлены ближе к изображению формы из руководства мастера-приёмщика. Бизнес-логика v3 сохранена.
- Контрагент: поля выровнены по скриншоту, настройки SMS/ЭДО/email разведены по строкам, добавлена вкладка «История аренды клиента».
- Автомобиль: окно подбора расширено до рабочей формы на весь экран, с 1С-подобными вкладками, кнопками вверху и тремя областями таблиц.
- Подсказки при наведении, самостоятельный ввод, учебные сценарии и экзаменационный режим сохранены.

## Проверки
- `node --check src/app.js` — успешно.
- `python qa/test_browser.py` — 10/10 ранее существующих интерактивных проверок успешно.
- `python qa/test_visual_fidelity.py` — режим формы 1С, карточка контрагента и полноэкранный подбор автомобиля успешно, ошибок JavaScript нет.
- В `qa/` лежат скриншоты формы Событие, карточки Контрагента и окна подбора автомобиля в режиме только формы 1С.

## Ограничения
- Из тестовой базы `aa6_ea_test9` не получен авторизованный эталон: визуал реконструирован **только по ранее предоставленным скриншотам инструкций**.
- Часть вкладок и сложных операций имеет учебную, а не полную серверную реализацию.
- Программные действия локальные; нет отправки реальных писем, MAX, изменения базы или реальной идентификации и аттестации сотрудников.
- Исходные скриншоты инструкций специально не включены в открываемую сборку, чтобы не копировать возможные данные клиентов и сотрудников.
