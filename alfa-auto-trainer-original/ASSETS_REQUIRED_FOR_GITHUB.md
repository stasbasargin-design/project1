# Медиафайлы для запуска репозитория

Публикация исходного кода в ветке GitHub не означает, что бинарные медиа автоматически доставлены. **Полная автономная сборка** со всеми оригинальными файлами находится в архиве `Alfa_Auto_Trainer_v13_1_Original_Based.zip`.

Для развёртывания исходников из GitHub нужно скопировать каталог `web-trainer-1c/assets/` **из этого архива**, сохраняя пути и имена. Папка включает контрольные скриншоты вашей 1С, 3 видео, субтитры VTT и постеры. Не заменяйте их стоковыми изображениями: именно они задают визуальное соответствие корпоративным экранам.

После извлечения убедитесь, что существуют файлы:

- `assets/event-production.png`
- `assets/desktop-production.png`
- `assets/zn-production.png`
- `assets/kp-production.png`
- `assets/training/video/01_incoming_call_calendar.mp4`
- `assets/training/video/02_event_to_ko.mp4`
- `assets/training/video/03_ko_in_bitrix24.mp4`

Полные размеры и контрольные суммы доступны в `FILE_MANIFEST_V13_1.json` внутри ZIP. **Основной сайт и тестовая 1С не изменены.**
