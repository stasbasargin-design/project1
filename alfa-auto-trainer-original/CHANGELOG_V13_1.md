# Альфа-Авто 6.1 — восстановление v13.1

**Основа:** исходный архив `Учебный_WEB-тренажер_1С_Альфа-Авто_6.1_v13_единый(1).zip`, полученный 18.11.2026. 

SHA-256 оригинала: `7c478e75a4a0294406050092f1c8846c6b2dfae8868c07f434b4e138e1cc5bf0`.

## Принцип релиза

Это **доработка v13 без переписывания**, а не упрощённая замена. Все исходные изображения формы, видеозаписи, субтитры, справочники, календарь, логика ЗН/КП/склада, интеграционные контракты и учебные условия остаются в комплекте.

### Конкретные изменения относительно исходного архива

1. **Восемь учебных модулей снова доступны.** В исходнике `trainingStagesLegacy` описывал 8 маршрутов, но навигация показывала только четыре экзамена `trainingStages`. Модули возвращены в общую последовательность, без удаления или переписывания их шагов.
2. **Четыре экзамена сохранены:** «Клиент пришёл», «Входящий звонок», «Исходящий звонок», «Передача в КО». В экзамене входящего звонка добавлены два шага дат КО; в экзамене передачи в КО — шаг «Общий вопрос».
3. **Оценки и журнал:** оценка завершённой попытки по шкале 0–100, штрафы 5 баллов за ошибочное действие/валидацию и 2 за подсказку, запись завершённых и прерванных попыток, выгрузка CSV (с защитой от формул при открытии в табличных редакторах). Восемь уроков не влияют на экзаменационные оценки.
4. **Задача CRM → группа КО:** добавлены поля «Дата записи предлагаемая», «Дата записи желаемая», «Общий вопрос». Они появляются только для телефонной задачи с темой «Телефонный звонок клиенту», назначенной группе/учебному сотруднику КО. Обе даты проверяются на интервал от текущего дня до 60 календарных дней. При «Общий вопрос» даты необязательны, но требуется заполненное содержание. Срок начала общей задачи по прежнему правилу ограничен месяцем.
5. **Ввод через Tab:** при прохождении экзамена заполнение ожидаемого поля с клавиатуры теперь засчитывается без предварительного щелчка на подсвеченном объекте.
6. **Регрессионная защита:** к исходному `tests/smoke.cjs` добавлены модульный тест оценок/CSV и автономный браузерный тест, проверяющий навигацию, исходные изображения, задачные поля, выгрузку CSV и сквозной экзамен «Передача в КО».

### Чего не меняли

- Не меняли исходный визуал экранов 1С и их координаты активных зон.
- Не меняли рабочую 1С, БД, Timeweb и опубликованный сайт.
- Не включали сетевую интеграцию с 1С: `config.js` по-прежнему содержит `mode: 'demo'`.
- Не отправляли учебные действия, письма и сообщения клиентам.

## Как запустить

Распакуйте архив и откройте `web-trainer-1c/index.html` в браузере. Вкладка «Обучение и экзамены» содержит 8 модулей и 4 экзамена; «Все объекты · учебная база» — свободную практику. Панель «Прогресс» содержит журнал и кнопку CSV. Вход на исходную страницу обучения с видео сохранён.

## Проверка

```sh
cd web-trainer-1c
node --check app.js
node tests/smoke.cjs
node tests/test-exam-history.cjs
python tests/browser-regression.py
```

Для браузерного теста требуется установленный Python `playwright` и Chromium. Тест использует полностью локальное содержимое и не обращается к Timeweb или рабочей 1С.
