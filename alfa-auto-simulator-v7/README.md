# WEB-тренажёр 1С:Альфа-Авто 6.1 — v7

Самостоятельная учебная реализация, не подключающаяся к рабочей или тестовой 1С. Все клиенты, машины, номенклатура и задачи в программе — вымышленные. Запуск: скачайте `AlfaAuto_Trainer_v7.html`, откройте в Chrome, Яндекс Браузере или Edge без установки.

## Главное в v7

1. Рабочий стол первой линии CRM переделан по **рисунку 1** документа `Инструкция_мастера-приемщика_1С_Альфа-Авто_6.1(2).docx`: три зоны «Не разобранное», «Подготовка к визиту», «Сделка», компактные строки сделок, зелёная/жёлтая/красная индикация, панель поиска и отбора.
2. **«Ответственные»** — не декоративная кнопка. Можно выбрать мастер-приёмщика, Приёмку, ОЗЧ и КО. На рабочем столе показываются задачи выбранных сотрудников/групп, а повторное открытие окна сохраняет отметки.
3. Поиск на рабочем столе отбирает видимые записи; переключатель «только с задачами» скрывает обычные сделки без задач.
4. Запись на ремонт на рабочем столе открывается по конкретному номеру, а не последняя редактировавшаяся.
5. В «Событии» «Причина обращения» — **краткая классификация**, а «Договорённость с клиентом» — **отдельное обязательное поле**, которое пользователь заполняет сам. Выбор причины больше не вставляет туда текст.
6. Проведение «События» допускается только при фактическом результате **самого текущего документа**: создан следующий документ, передано через задачу CRM, указано связанное основание либо событие отменено. Состояние прошлых обращений не засчитывается.
7. Проведённые события сохраняются в учебной истории с отдельными номерами `СБ-00001`, `СБ-00002` и результатами. Добавлен отдельный 17-й сценарий «Событие: повторное обращение по сделке».
8. Маршрут КП → ОЗЧ → согласование, печать, запись на ремонт и сохранение нескольких КП сохранены из v6.

## Запуск исходного проекта

`index.html` ссылается на `src/styles.css`, `src/skin.css`, `src/app.js`. Для сборки самодостаточного HTML выполните `python build.py`. Никакой API ключ или сетевой доступ не требуется.

## Источники и границы точности

Основной эталон для рабочего стола: оригинальное изображение из `Инструкция_мастера-приемщика_1С_Альфа-Авто_6.1(2).docx` (раздел «Начало смены: рабочий стол первой линии», рисунки 1–3). Логика КП — `Работа КП(1).docx`; авто-КП — `Автоматическая КП по дефектовке.docx`. Все документы прочитаны без копирования внутренних изображений и реальных реквизитов в публичный релиз.

Точная идентичность с актуальным веб-клиентом `aa6_ea_test9` **не подтверждена**: веб-клиент недоступен для авторизованного просмотра из этого окружения. Не подтверждено расположение полей «Запись на ремонт» по текущей базе; в тренажёре оно реконструировано по описанию процесса. Не реализованы серверные регистры 1С, реальные нормативы, склад, рассылки и проводки. Кнопки симуляции явно маркированы учебными.

Настоящая 1С, Bitrix24, MAX, сайт ea-itus.ru, PostgreSQL и основная ветка GitHub не изменяются.
