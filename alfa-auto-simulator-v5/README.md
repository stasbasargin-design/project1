# 1С:Альфа-Авто 6.1 — самостоятельный WEB-тренажёр v5

Откройте `AlfaAuto_Trainer_v5.html` в Chrome, Edge или Яндекс Браузере. Интернет не требуется. Все данные вымышлены, сохраняются в браузере. Настоящие 1С, MAX, CRM и почта не вызываются.

## Основное изменение v5

Связанные учебные сценарии вместо отдельной имитации форм:

Кнопки «Учебное событие: дефектовка» и «Учебный ответ клиента» специально обозначены как **кнопки тренажёра**, а не команды 1С. В режиме «Вид только формы 1С» они скрыты.

- «Системное сообщение о дефектовке» на рабочем столе создаёт учебную авто-КП и задачу «Подготовить КП…» для группы приёмки. Повторное сообщение не создаёт второй КП; создаётся задача ознакомления с уже существующей.
- Групповую задачу нужно принять в работу в окне «Принять документ к исполнению?», после чего назначается текущий учебный исполнитель.
- Из задачи по предмету открывается КП. Статус «Согласование» при успешной записи автоматически завершает задачу подготовки и создаёт отдельную задачу «Согласовать КП…». Обычная ручная КП такого перехода не запускает.
- «Проценить» создаёт реальную запись в локальной учебной очереди задач ОЗЧ, а после её завершения появляется задача на доработку КП.
- В записи на ремонт можно смоделировать подтверждение, перенос, отмену или отсутствие ответа. При переносе и отмене создаётся задача для приёмки, срок ответа условно отображается +30 минут; для отсутствия ответа можно вручную запустить сценарий обзвона.
- Создание и сохранение обычной задачи CRM тоже добавляет её в учебную очередь, а завершение требует текста результата.

Сохранены предыдущие формы, подсказки при наведении, экзаменационный режим, подборы КП и существующие 13 сценариев. Добавлены сценарии «Авто-КП» и «Подтверждение записи», всего 15.

## Проверка

`node --check src/app.js`; `python qa/test_v5_browser.py` — тесты работы в Chromium Playwright без сетевых подключений.

## Ограничения

Точный визуал и все серверные переходы не подтверждены на живом `aa6_ea_test9`: доступ к этой базе из текущей среды всё ещё не получен. Эталон визуала — предоставленные пользователем скриншоты из внутренних инструкций. Учебные данные/цены/сроки условные; системные события не срабатывают по реальному времени. Реконструированная запись на ремонт требует отдельной визуальной сверки с текущей 1С.
