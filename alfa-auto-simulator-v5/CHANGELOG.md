# Изменения v4 → v5 — 19.11.2026

1. Введена отдельная учебная очередь «Задачи CRM» с состояниями задач, ответственным, документом-основанием и результатом.
2. Рабочий стол отображает фактически созданные в симуляторе задачи и записи, а не фиксированные демонстрационные счётчики.
3. Имитация **завершения дефектовки** создаёт учебную авто-КП, заполняет её только данными системного учебного события и создаёт задачу «Подготовить КП…» для группы приёмки.
4. **Повторная дефектовка** не создаёт второй КП; формируется задача ознакомления. В текущей модели действует одна учебная пара ЗН→авто-КП.
5. Групповые задачи требуют принятия к исполнению с изменением ответственного.
6. Переход из задачи к документу открывает связанную калькуляцию; после успешной записи её со статусом «Согласование» задача подготовки закрывается и создаётся задача согласования.
7. Обычная ручная КП не запускает автоматический процесс дефектовки.
8. «Проценить» и «Заказать» создают записи в учебной очереди ОЗЧ. Завершение проценки возвращает задачу на доработку КП.
9. Завершение задачи требует фактического результата. Задачу согласования нельзя завершить, пока КП не имеет итогового статуса («Согласована», «Частично согласована», «Отклонена»).
10. Имитация **ответа на подтверждение записи**: подтвердил — запись обновлена; перенос/отмена — задача группе приёмки; нет ответа — задача «Обзвон клиента».
11. Исправлено повторное создание документов из события — поля прошлой записи не переносятся в новый документ автоматически.
12. Добавлены 2 сценария (всего 15) и регрессионные тесты.

Не осуществлялись подключения, выгрузки или изменения настоящей 1С, MAX, PostgreSQL и GitHub main.
