# ИТУС Service MAX 2.0 — готовое приложение для подключения к 1С

В комплекте реализованы интерфейс, мобильные сценарии, работа камеры и
микрофона, динамические анкеты, отправка файлов как Base64 в JSON, B2B-чат,
межотдельский чат, уведомления и скачивание PDF. Разработчику 1С требуется
реализовать HTTP-методы по контракту `1C_HTTP_METHODS_RELEASE.json` и вернуть
указанные JSON-структуры. Изменять код приложения для состава анкет не нужно:
поля и вопросы строятся из ответа 1С.

## Что реализовано

- вход по MAX ID и QR, передача ID в каждом запросе;
- загрузка доступных заказ-нарядов и проверка прав;
- акт приёма: создаётся кнопкой, форма приходит из 1С, после завершения скрывается;
- выбор постов по правам пользователя;
- сначала плановый исполнитель, затем отдельный выбор из общего списка;
- уведомление назначенного исполнителя через событие 1С;
- контрольный лист только после кнопки «Начать работу»;
- создание/запуск/перерыв/закрытие пакета УРВ и реальная выработка из 1С;
- создание или получение дефектовочной ведомости из дерева ЗН;
- текстовый чат дефектовки, фото с камеры, видео, голосовые сообщения и запрос распознавания;
- выходной контроль технолога с анкетой из 1С;
- автоматическое открытие ЗН технологу по событию `quality_control_requested`;
- причина текущего обращения из 1С;
- формирование в 1С и скачивание PDF «История обслуживания»;
- B2B-переписка с клиентом через 1С с файлами, фото и видео;
- активный чат между отделами через 1С с вложениями;
- отсутствие демонстрационных данных и статических ответов.

## Быстрый запуск в Windows

1. Установите Node.js 20 LTS или новее.
2. Распакуйте архив.
3. Запустите `START_WINDOWS.bat`.
4. Откройте `http://localhost:8080`.
5. Введите числовой ID пользователя MAX.

Не открывайте `index.html` двойным щелчком: камера, микрофон и запросы к 1С
должны работать через `START_WINDOWS.bat`, HTTPS-домен или localhost.

## Команды

```text
npm start            production-запуск на http://localhost:8080
npm test             тест нормализации JSON
npm run check:api    проверка опубликованного API 1С
npm run dev          режим разработки Vite после npm install
npm run build        пересборка папки dist
```

## Настройка адреса 1С

Для локального и production-запуска браузер обращается к `/api/1c`, а
`server.mjs` проксирует запросы в HTTP-сервис 1С. Целевой адрес по умолчанию:

```text
https://1c.eazia.ru/aa6_ea_test9/ru/hs/max-service
```

Параметры сервера:

```bat
set ONE_C_TARGET=https://1c.eazia.ru/aa6_ea_test9/ru/hs/max-service
set ONE_C_TOKEN=СЕКРЕТНЫЙ_ТОКЕН
set PORT=8080
set MAX_REQUEST_BYTES=31457280
node server.mjs
```

Секрет `ONE_C_TOKEN` хранится только на сервере. Не записывайте токены MAX или
1С в `config/itus.config.js`.

## Основные файлы

- `1C_HTTP_METHODS_RELEASE.json` — точный машинный контракт запросов и ответов;
- `MAX_JSON_SCHEMA_RELEASE.json` — контекст MAX и webhook;
- `1C_SECURITY_AND_CONTRACT.md` — требования к защите и устойчивости;
- `config/itus.config.js` — публичные настройки;
- `dist/` — готовая production-сборка;
- `server.mjs` — статический сервер и same-origin proxy в 1С.

## Важные ограничения

- Один файл ограничен 15 МБ; фотография автоматически сжимается в браузере.
- Тело JSON на сервере ограничено 30 МБ и настраивается `MAX_REQUEST_BYTES`.
- Для камеры и микрофона нужен HTTPS или `localhost`.
- Приложение опрашивает `/notifications/poll` каждые 15 секунд; интервал меняется
  параметром `POLL_INTERVAL_MS`.
