# ИТУС MAX 2.1.7 — восстановленный комплект

Основа — присланный вами рабочий архив ITUS_Service_MAX_FULL (2).zip, версия 2.1.0.

## Запуск для проверки

1. Распакуйте весь архив в новую папку. Не смешивайте его с файлами предыдущих выпусков.
2. Закройте окно сервера предыдущего выпуска, если он занимает порт 8080.
3. Запустите START_WINDOWS.bat (требуется установленный Node.js 20 или новее).
4. Откройте http://localhost:8080/p/max-service/ и обновите страницу сочетанием Ctrl+F5.

Готовая сборка dist включена. Ключ администратора не нужен: поля ключа, отдельного API настроек и зависимости от него здесь нет. Окно подключения снова работает как в вашем исходном архиве: показывает адреса, позволяет проверить связь и перезагрузить данные.

## Подключение и JSON

Сохранены исходные config/itus.config.js, vite.config.js, схемы MAX_JSON_SCHEMA_RELEASE.json и 1C_HTTP_METHODS_RELEASE.json. Адрес 1С: https://1c.eazia.ru/aa6_ea_test9/ru/hs/max-service.

Локальный маршрут сервера — /api/1c. Как в исходном архиве, при открытии страницы в /p/max-service/ браузер использует /p/max-service/api/1c; сервер принимает оба варианта и отправляет запрос в ту же 1С. Изменение адресов через отдельный сервер настроек из неработавших выпусков убрано. Если потребуется другая база, ONE_C_TARGET задаёт адрес серверного прокси; ONE_C_PUBLIC_BASE_URL в config/itus.config.js — отображаемый адрес. После изменения браузерной конфигурации выполните npm run build.

## Исправления

- Восстановлена схема запуска и подключения из вашего рабочего архива. Нет запросов к _itus/settings и нет блокировки приложения из-за HTML вместо JSON настроек.
- Устранён ошибочный FORBIDDEN для обычных файлов на Windows: проверка пути учитывает разделители Windows.
- При наличии ссылки на действующую дефектную ведомость вложение отправляется в неё без вызова /defects/start. Если ссылки в карточке нет, приложение сначала обновляет заказ через /orders/get. Новый документ запрашивается только при отсутствии действующего. Одновременные действия не запускают повторное создание в рамках этой страницы.
- Если 1С не вернула корректную ссылку документа, отправка вложения останавливается с сообщением об ошибке.

Дизайн, логотип, расположение разделов и исходные JSON-контракты сохранены.

## Проверка

Пройдены тесты нормализации, анкеты приёма, вложений в существующий документ, одновременного запроса ведомости, Windows/UNC/Linux-путей, локального и вложенного HTTP-маршрута и исходного JSON-контракта. Windows-пути проверены программно; запуск на компьютере Windows в этой сессии не выполнялся.

Полные бизнес-операции с реальной базой (создание, завершение, запись файлов) не выполнялись. Размещение на ea-itus.ru этим архивом автоматически не изменяется: для сайта сохраняется схема проксирования из исходного deploy/ea-itus-location.conf. Подробности — START_HERE.md.
