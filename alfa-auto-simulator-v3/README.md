# WEB-тренажёр 1С:Альфа-Авто 6.1 — v3 «Визуальное соответствие»

**Дата:** 19.11.2026.  
**Статус:** самостоятельная интерактивная учебная версия, прошла браузерные smoke-тесты; **не является полной визуальной копией текущей тестовой 1С**.

## Как открыть

1. Скачайте `AlfaAuto_Trainer_v3.html` (или одноимённый русский вариант) и откройте двойным щелчком в Chrome, Edge или Яндекс Браузере. Интернет не нужен.
2. Для запуска из исходников разместите **в одной папке** `index.html` и каталог `src` со всеми тремя файлами (`app.js`, `styles.css`, `skin.css`). Откройте `index.html`.
3. Нажмите **«Сценарии»** и выберите учебный маршрут. **«Справка»** открывает объяснения. При наведении на объект появляется подсказка. **«Обучение»** переключается в **«Экзамен»** без подсказок.
4. Список справочника: поиск по строке; один клик выделяет запись, двойной открывает карточку. Новые карточки создаются пустыми. Системные значения подставляются только по предусмотренному сценарию.
5. Результаты сценариев хранятся **только в браузере**. Для очистки нажмите «Сбросить учебные данные».

## Что построено

- Новая самостоятельная оболочка 1С в масштабе реальных управляемых форм (верхняя навигация, вкладки, панели команд, реквизиты, табличные части, диалоги).
- Переносимые панели обучения, которые не меняют расположение полей 1С и могут быть закрыты.
- Подробные подсказки при наведении и переходе клавишей Tab; отдельные учебные сценарии и режим экзамена со штрафом за ошибочные действия.
- 15 генераторов экранов: рабочий стол CRM, событие, задача CRM, контрагенты и контакты, карточка контрагента, автомобили, карточка автомобиля, калькуляция, заказ-наряд, экспресс ЗН, MAX, блокировка, Email, заявка на ремонт, журнал обучения.
- 13 учебных маршрутов с проверками действий.
- Справочник контрагентов и автомобилей: поиск, выделение строки, двойной клик, открытие существующей карточки, самостоятельное создание.
- Карточка контрагента: поиск по ИНН → отдельное окно выбора → заполнение только после подтверждения.
- Карточка автомобиля: VIN и шасси → интерактивное окно с отдельными таблицами марок, моделей и комплектаций → «Применить».
- Калькуляция: пустые табличные части; массовый подбор работ и товаров, ввод количества и стоимости.
- Событие: распределение блоков близко к скриншотам; перенос причины в договорённость; поиск автомобиля по части госномера/окончанию VIN.
- Задача КО: дата и время, условные поля, 60-дневное ограничение, перенос дат в содержание.
- Блокировка: учебное предупреждение с действиями «Да», «Нет», «Отмена» и вкладка «Разблокировка».
- Email и MAX не отправляют реальные сообщения.

## Проверки

- `node --check src/app.js` — успешно.
- `python qa/test_browser.py` — **10/10 интерактивных браузерных проверок**, ошибок JavaScript не выявлено.
- Браузерные тесты открывают HTML через `page.set_content` без обращения к локальным или внешним адресам; в этой среде прямые `file://`/`http://` переходы могут быть заблокированы администратором.
- Результаты: `qa/test_browser_results.json`; превью: `qa/v3-event-1600.png`, `qa/v3-counterparty-1600.png`, `qa/v3-vehicle-1600.png`.

## Что ещё не считается завершённым

1. **Нет сверки с живой `aa6_ea_test9`:** доступ к тестовой базе из данной среды не получен. Попиксельное совпадение можно подтвердить только сравнением с её актуальными формами.
2. В части дополнительных вкладок и сложных процессов (полная логика АвтоКП, все варианты КП/ЗН, связка MAX с документами, полноценные финансовые регистры и email-дерево) пока существует учебная модель, но не вся бизнес-логика реальной 1С.
3. Видео с реальной работой 1С не записывались и не включены. Скрипты — учебные сценарии в `app.js`, не настоящие серверные скрипты конфигурации.
4. Экзамен оценивает конкретные учебные сценарии, но не является официальной аттестацией без серверного хранения и идентификации пользователей.

## Безопасность

В приложении нет подключения к реальной 1С, 1С API, SMS, MAX, SMTP, БД или внешним сервисам. Данные примеров вымышлены; работа происходит локально в браузере. Разработка велась отдельно от работающего сайта, базы и основной ветки репозитория.
