# WEB-тренажёр 1С:Альфа-Авто 6.1 — v4

**Самостоятельное учебное приложение; не подключается к рабочей или тестовой 1С.**

## Как запустить

Скачайте `AlfaAuto_Trainer_v4.html` и откройте в Chrome, Edge или Яндекс Браузере. Интернет не требуется. Для работы с исходниками храните `index.html` и папку `src` рядом.

## Что изменено в v4

**Калькуляция (КП):** форма «Основное» реконструирована по внутренней инструкции `Работа КП(1).docx`, в том числе по рисунку документа «Основная Калькуляция». Реализованы группы реквизитов «Клиент», «Автомобиль», «Контакты», «Плательщик», «Описание ремонта», «Временные рамки», «Маркетинговая программа», «Причины обращения». Вкладки КП: «Основное», «Товары», «Автоработы», «Рекомендации товары», «Рекомендации работы», «Калькуляции по сделке». Обязательные поля: контрагент, договор, автомобиль, способ оплаты. Новые табличные части пустые.

Позиции: добавление пустой строки, подбор из учебного справочника, диалог связанных запчастей для авторабот, ввод количества, цены, нормочасов, учебного остатка, поставщика и срока поставки, пересчёт суммы. Отметки «Согласовано», «Рекомендовано», «Деталь клиента» взаимоисключаемые. Согласованные работы/товары переносятся в ЗН, товары с «Деталь клиента» — в «Материалы заказчика», рекомендации привязываются к автомобилю. ОЗЧ: команда «Проценить» создаёт учебную задачу с комментарием, «Заказать» — задачу по согласованным товарам. Печатные формы КП: четыре пункта, учебный переход в Email.

**Запись на ремонт:** отдельная полноценная учебная форма с поиском клиента и автомобиля, датой и временем, подразделением, ответственным и причиной. Проверка обязательных полей, сохранение и открытие записей из локальной учебной истории, продолжение в заказ-наряд. Наименование в меню изменено на «Запись на ремонт».

**Заказ-наряд:** группы полей, самостоятельные вкладки «Основное», «Автоработы», «Товары», «Материалы заказчика», «Результат ремонта»; перенос из КП с правильной логикой флажков. Выделенные учебные материалы заказчика не попадают в обычные товары.

**Подсказки и экзамены:** существующие 13 учебных сценариев, 15 экранов и контекстная справка сохранены. При навигации из панели «Сценарии» она автоматически скрывается, не закрывая форму. Изменение строк не вызывает преждевременной перерисовки (предотвращена потеря нажатия).

- `python qa/test_v4_browser.py` — 9/9 браузерных проверок успешны, ошибок JavaScript нет. Выполняются в браузере Playwright Chromium, без сетевых вызовов.

## Точность и ограничения

Источник визуала КП: реальные скриншоты из `Работа КП(1).docx`, в т. ч. титульная форма «Основная Калькуляция», кнопки подбора, табличные части и флажки; дополнение — `Инструкция_мастера-приемщика_1С_Альфа-Авто_6.1(2).docx` и `Автоматическая КП по дефектовке.docx`. Скриншота **полной формы записи на ремонт** среди этих материалов не было; форма записи — осмысленная реконструкция процесса из инструкций, **её точное визуальное соответствие не подтверждено**.

В `aa6_ea_test9` из текущего окружения не удалось войти, поэтому данный выпуск **не проверен по актуальной живой базе**. Системные сообщения, остатки, связывание позиций и задачи ОЗЧ смоделированы на вымышленных данных. Регистр и API 1С не подключены; настоящие письма/MAX не отправляются. Автоматические процессы после дефектовки моделируются только в учебной логике; ручная смена статуса обычной КП не должна выдаваться за триггер серверной автоматики.

Выгрузки/скриншоты исходных рабочих документов **не включены в сборку**, чтобы не распространять реальные данные клиентов или сотрудников. Рабочий сайт, боевая и тестовая 1С и `main` репозитория не затрагивались.
