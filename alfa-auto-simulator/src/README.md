# Альфа-Авто 6.1 · Новый учебный WEB-симулятор

**Сборка:** самостоятельный новый продукт, не основанный на старой v13.1.

## Начать работу
1. Откройте `Альфа-Авто_Тренажер_Новый.html` в Chrome / Яндекс Браузере / Edge двойным щелчком. Интернет не нужен.
2. Слева выберите нужный документ. Для последовательной практики выберите сценарий из раздела «Сценарии по документам».
3. Наведите указатель на любое поле, таблицу, вкладку или кнопку — появится пояснение. Пояснение одновременно видно справа.
4. С помощью кнопки «? Подсказка по шагу» можно подсветить поле следующего шага на форме.
5. Кнопка «Наставник» вверху скрывает боковые панели и показывает расширенную рабочую форму, близкую по расположению к экрану 1С.
6. Данные новых документов вводятся самостоятельно. Учебные записи находятся только в справочниках, выбор через кнопку «…».
7. Прогресс сохраняется в этом браузере и выгружается в CSV.

## Что уже реализовано
- Визуальная оболочка по реальным образцам интерфейса из предоставленных инструкций;
- Рабочий стол первой линии CRM;
- Документ «Событие», «Задача CRM» с условными полями группы КО;
- Контрагенты, Контактные лица, карточка автомобиля и выбор комплектации;
- Калькуляция с пустыми строками и подбором из справочников, заказ-наряд, экспресс ЗН;
- Заявка на ремонт, MAX, запрос разблокировки, отправка email;
- 13 учебных сценариев с пошаговой проверкой и подсказками;
- Диалоговые справочники с поиском, выбором строки и работой с клавиатурой;
- Локальное хранение, без отправки данных на сервер.

## Важные ограничения
- Это **версия 1.0 нового продукта**, а не точная копия рабочей конфигурации. Внешние элементы и расположение реализованы по исходным скриншотам, но 100% визуальное и функциональное соответствие рабочей 1С ещё не подтверждено.
- Некоторые редко используемые вкладки информационные; реальные 1С, телефония, MAX, отправка писем и БД не подключены.
- Учебные контрагенты/контакты/автомобили вымышлены. Вносите только тестовые данные.
- Видео по реальной рабочей базе не записывались; вместо них предусмотрены интерактивные инструкции и подсветка действий.
- Состояние сохраняется в браузере на конкретном устройстве, серверного журнала и прав сотрудников пока нет.

## Файлы
- `Альфа-Авто_Тренажер_Новый.html` — автономный файл, всё включено;
- `index.html`, `styles.css`, `app.js` — исходники для публикации на отдельном тестовом веб-хостинге;
- `qa/` — результаты локальных тестов и скриншоты (необязательная часть выпуска).

**Проверено:** статический JavaScript Node.js; рендеринг 15 страниц; браузерный smoke-тест переходов, справочников, форм и условных полей КО без ошибок консоли.
